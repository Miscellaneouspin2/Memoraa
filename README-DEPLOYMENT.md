# Deployment

1. Upload every ZIP item to repository root, preserving the `assets/` folder.
2. Replace matching Step 10 files.
3. Keep GitHub Pages branch `main` and folder `/(root)`.
4. Verify all legal links, language/theme persistence, cookie choices, private-page no-store headers and service-worker cache.
5. Do not insert secrets into HTML, JavaScript, GitHub or `config.placeholders.env`.
6. Complete professional legal/accounting review before live payments or personal-data processing.
