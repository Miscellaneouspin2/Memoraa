PROJECT OVERVIEW
----------------------------------------------------

Memoraa is a premium personal website platform designed
to help individuals and families preserve and celebrate
important life moments through beautifully crafted
web experiences.

Supported categories include:

- Birthday Websites
- Valentine Websites
- Engagement Websites
- Marriage Websites
- Anniversary Websites
- Memorial Websites
- Family Event Websites
- Personal Story Websites
- Custom Personal Websites
- Special Solutions

The platform includes:

1. Mother Website
2. Customer Workspace
3. Admin Dashboard
